11.Animation:
    animate-spin: Constant 360° clockwise rotation.
    animate-ping: Element grows and fades like a radar ripple.
    animate-pulse: Gently fades opacity in and out.
    animate-bounce: Moves the element up and down playfully.

13.Box shadow & ring:
    shadow-sm: A subtle, tiny shadow.
    shadow: The standard default shadow.
    shadow-md: Medium-sized shadow.
    shadow-lg: Large, soft shadow (popular for cards).
    shadow-xl: Extra-large shadow for significant elevation.
    shadow-2xl: Maximum depth.
    shadow-none: Removes any existing shadow.
    shadow-blue-500: Adds a blue glow.
    shadow-black/50: Adds a black shadow with 50% opacity.
    shadow-indigo-500/40: Indigo shadow with specific transparency.

15. Pseudo classes, elements:
    Common Pseudo-classes (States)
    Interaction: hover:, focus:, active:, visited:, focus-within:, focus-visible:.
    Form States: disabled:, required:, invalid:, checked:, read-only:, placeholder-shown:, autofill:.
    Structure: first:, last:, odd:, even:, only:, nth-{n}:, first-of-type:, empty:. 

    Pseudo-elements:
    Content Injection: before:, after: (automatically sets content: "" if not specified).
    Typography: first-letter:, first-line:, marker: (for list bullets).
    Selection & Inputs: selection: (highlighted text), placeholder:, file: (file input buttons).

    Advanced Selectors
    group: Add this to a parent to style children based on parent state (e.g., group-hover:text-blue-500).
    peer: Add this to a sibling to style subsequent siblings (e.g., peer-invalid:visible).
    has-{condition}: Styles an element if it has a specific descendant (e.g., has-[:checked]:bg-blue-100).
    *:text-sm [applies to all child]
